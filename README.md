# Proyecto MasterBikes — Metodología de Desarrollo Ágil (TI3V23)

Documentación de un proyecto informático con Scrum para la **Fábrica de Bicicletas "San Diego" → MasterBikes**:
una plataforma web de venta, arriendo, reparación, insumos y despacho, integrada con los servicios web de SHIMANO.
**El curso no pide programar, solo documentación.**

Camilo Sepúlveda (Developer backend y BD) · Logan Silva (Developer frontend y UX/UI)
**Proyecto simulado:** 23-nov-2026 → 12-feb-2027 (12 semanas: Sprint 0 + 5 sprints de 2 semanas + Cierre)

**Repositorio (público):** https://github.com/digicamilo-lgtm/taller-de-bicicletas

## Convenciones
- **Nombres:** `<Documento>_MasterBikes_vX.Y.<ext>`. Una nueva versión es un archivo nuevo; las anteriores no se sobrescriben.
- **Versionado:** se sube el número menor (v1.0 → v1.1) por correcciones y el mayor (v1.x → v2.0) por cambios de alcance o de entrega.
- **Registro:** al cerrar cada sesión se actualizan BITACORA (qué se hizo) y HITOS (estado). Las decisiones van en DECISIONES.
